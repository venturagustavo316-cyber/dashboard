PROJETO: DASHBOARD FINANCEIRO WEB

TECNOLOGIAS:

* HTML5
* CSS3
* JavaScript
* LocalStorage
* SVG ou biblioteca de gráficos somente em uma etapa posterior

OBJETIVO DO PROJETO:

Criar uma aplicação web de controle financeiro pessoal com aparência de dashboard moderno.

O usuário deverá conseguir cadastrar receitas e despesas, visualizar o saldo atual, acompanhar quanto recebeu e gastou, visualizar suas movimentações e analisar os dados por meio de gráficos.

O projeto deverá ser desenvolvido inicialmente somente com HTML, CSS e JavaScript puro, sem React, Vue, Angular ou outro framework.

A ideia principal é aprender como uma aplicação web funciona de verdade, separando:

HTML = estrutura
CSS = aparência
JavaScript = lógica e comportamento
LocalStorage = armazenamento dos dados

6. ETAPA 4 — CALCULAR AS INFORMAÇÕES
====================================

O JavaScript deverá calcular automaticamente:

RECEITAS

Somar todas as movimentações cujo tipo seja:

"receita"

DESPESAS

Somar todas as movimentações cujo tipo seja:

"despesa"

SALDO

Saldo = receitas - despesas

Exemplo:

Receitas = R$ 4.000

Despesas = R$ 1.550

Saldo = R$ 2.450

Criar funções separadas.

Exemplo conceitual:

calcularReceitas()

calcularDespesas()

calcularSaldo()

atualizarResumo()

Não colocar toda a lógica dentro de uma única função gigantesca.

7. ETAPA 5 — FORMATAÇÃO DE DINHEIRO
===================================

Os valores internamente poderão ser números:

4000
350
1550

Mas na interface deverão aparecer como:

R$ 4.000,00
R$ 350,00
R$ 1.550,00

Utilizar:

Intl.NumberFormat

Exemplo:

const formatarMoeda = new Intl.NumberFormat("pt-BR", {
style: "currency",
currency: "BRL"
});

Depois:

formatarMoeda.format(4000);

Resultado:

R$ 4.000,00

Não armazenar "R$ 4.000,00" como valor.

O valor deverá continuar sendo um número.

13. ETAPA 11 — LOCALSTORAGE
===========================

Até esse ponto, se o usuário fechar o navegador, os dados serão perdidos.

Agora implementar:

localStorage

O navegador permitirá salvar os dados localmente.

Fluxo:

Array JavaScript

↓

JSON.stringify()

↓

localStorage

Para recuperar:

localStorage

↓

JSON.parse()

↓

Array JavaScript

Criar funções:

salvarDados()

carregarDados()

Ao abrir a aplicação:

carregarDados()

↓

renderizarMovimentacoes()

↓

atualizarResumo()

Assim, os dados continuarão disponíveis depois de fechar e abrir o navegador.
